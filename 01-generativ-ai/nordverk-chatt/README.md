# nordverk-chatt

Ett litet Vue 3-projekt som pratar med en språkmodell. Det används i kapitel
2–5 i [modul 01](../README.md).

## Starta

Filen `.env` med din nyckel måste finnas i **repots rotmapp** (se
[kapitel 2](../02-kom-igang.md)). Öppna sedan en terminal i den här mappen och
skriv:

```
npm install
npm run dev
```

Öppna <http://localhost:5173> i webbläsaren.

All kod du skriver hamnar i `src/App.vue` (och i kapitel 5 i
`src/Serviceprotokoll.vue`).

## Facit

I mappen `facit/` finns hur filerna ser ut efter varje kapitel. Kopiera en fil
till `src/App.vue` om du har kört fast. `Serviceprotokoll.vue` kopierar du till
`src/`.
