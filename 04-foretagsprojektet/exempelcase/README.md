# Exempelcase

Tre övningscase med **påhittad** testdata. Företagen, personerna och all data är
påhittade. Likheter med verkliga företag eller personer är oavsiktliga.

Använd dem för att öva på utredningen och startprojektet innan ert riktiga case
kommer, eller som reserv om företagscaset dröjer.

| Case | Uppgift | Övar särskilt på |
|---|---|---|
| [01 – Månadsrapport](01-manadsrapport-service/) | Skapa en rapport från serviceprotokoll och en larmlista | Rapport från befintliga rapporter, datakvalitet, siffror som måste stämma |
| [02 – Kundärenden](02-kundarenden/) | Sortera ärenden och föreslå svar | Personuppgifter, att lura modellen med text i datan |
| [03 – Teknisk dokumentation](03-teknisk-dokumentation/) | Svara på frågor om tekniska dokument | Sekretess och exportkontroll, lokal modell |

Varje case har en `README.md` skriven som från företaget och en mapp `testdata/`.
